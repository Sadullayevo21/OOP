# 🚗 Transport Car Project

Bu loyiha C# OOP asosida yozilgan `Car` klassidan iborat. Mashina tezligi, yoqilg‘i va manzil boshqaruvi amalga oshirilgan.

## Imkoniyatlar

- Speed property
- IncreaseSpeed()
- DecreaseSpeed()
- Destination property
- FuelLevel property
- Drive()
- Refuel()

## Ishlash qoidasi

- Har 10 km yo‘l uchun 1% yoqilg‘i sarflanadi.
- Yoqilg‘i 0 bo‘lsa manzil o‘zgarmaydi.
- Yoqilg‘i 100% dan oshmaydi.
- Tezlik manfiy bo‘lishi mumkin emas.
